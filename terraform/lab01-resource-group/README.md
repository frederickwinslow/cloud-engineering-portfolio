# Terraform Lab 01 - Azure Resource Group

## Overview

This project creates an Azure Resource Group using Terraform.

## Technologies

- Microsoft Azure
- Terraform
- Git
- GitHub

## Resources Created

- Azure Resource Group

## Azure Region

South Africa North

## Terraform Workflow

The Terraform workflow used in this project is:

1. `terraform init`
2. `terraform fmt`
3. `terraform validate`
4. `terraform plan`
5. `terraform apply`
