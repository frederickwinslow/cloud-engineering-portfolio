# Azure Cloud Application Lab

A hands-on cloud engineering project demonstrating how to build and deploy a Python web application to Microsoft Azure App Service.

## Project Overview

This project involved developing a simple internal **Company Document Portal** using Python and Flask and deploying it to Azure App Service.

The application provides a basic web interface where employees can view company information and access internal document resources.
